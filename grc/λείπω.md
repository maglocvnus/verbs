# λείπω

`λείπω` (leípō) ‘leave, abandon’ is an Ancient Greek (transitive) verb.


## Aorist indicative active

The aorist indicative active forms of the verb `λείπω` are as follows:

| | singular | dual | plural | 
| -- | -- | -- | -- |
| **first**	| ἔλιπον | | ἐλίπομεν |
| **second**	| ἔλιπες | ἐλίπετον | ἐλίπετε	|
| **third**	| ἔλιπε(ν) | ἐλιπέτην | ἔλιπον |

Transliteration:

| | singular | dual | plural | 
| -- | -- | -- | -- |
| **first**	| élipon | | elípomen |
| **second**	| élipes | elípeton | elípete	|
| **third**	| élipe(n) | elipétēn | élipon |

Notes:
- the augment ἐ marks past time in the indicative
- the aorist stem λιπ- is the zero-grade of the root λειπ-/λοιπ-/λιπ-
- -ε- or -ο- is the thematic vowel
- the personal endings are: -ν, -ς, -μεν, -τον, -την, -τε
- these are all second/thematic aorist forms, since they do not exhibit the characteristic -σα- formation of a first aorist.
